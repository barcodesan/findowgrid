# FindowGrid

**FindowGrid**는 HTS, 차트, 뉴스, 브라우저 등 여러 투자 관련 창의 위치를 저장하고 한 번에 복원하는 Windows 프로그램입니다.

## 사용법

### 1. 화면 배치하기
평소처럼 HTS, TradingView, 뉴스 등을 원하는 위치에 배치하세요.

### 2. Workspace 저장하기
FindowGrid에서 **`Save Current Workspace`**를 누르고 이름을 지정합니다.

예:
- 국내주식
- 미국주식
- FX
- 뉴스/리서치

### 3. Workspace 불러오기
저장된 Workspace에서 **`OPEN`**을 누르면 등록된 창들이 저장했던 위치로 돌아갑니다.

단축키를 지정했다면 FindowGrid를 직접 열지 않고도 바로 전환할 수 있습니다.

### 4. 배치 수정하기
창 위치를 원하는 대로 다시 조정한 뒤 **`Update with Current Screen`**을 누르면 새로운 배치로 업데이트됩니다.

## 알아두기

FindowGrid는 **HTS 자체를 수정하거나 주식 계좌에 접근하지 않습니다.**

HTS, 브라우저 등의 Windows 창을 찾아 **위치와 크기를 저장하고 복원하는 역할만** 합니다.

즉,

**화면 배치 → 저장 → 필요할 때 한 번에 복원**

이게 전부입니다.
