# findowgrid

**자주 사용하는 프로그램과 웹사이트의 창 배치를 저장하고, 클릭이나 단축키 한 번으로 복원하는 Windows Workspace Manager입니다.**

HTS, TradingView, 뉴스, 경제 캘린더 등을 원하는 위치에 배치한 뒤 하나의 Workspace로 저장하세요. FX, 한국주식, 미국주식, 리서치 등 용도별 작업 환경을 만들 수 있습니다.

## 주요 기능

- **Workspace 저장·복원** — 여러 창의 위치, 크기, 최소화·최대화 상태 저장
- **앱 실행** — 실행 중인 창은 재사용하고, 없는 앱은 등록된 실행 설정에 따라 실행
- **멀티모니터 지원** — 모니터 연결이 바뀌면 사용 가능한 화면 안으로 배치 조정
- **전역 단축키** — Workspace별 단축키 지정 및 충돌 안내
- **배치 미리보기** — 저장된 창 배치를 간단한 도식으로 표시
- **시스템 트레이** — 메인 창을 닫아도 트레이에서 Workspace 실행
- **자동 시작** — Windows 로그인 시 실행 및 마지막 Workspace 복원 옵션

## 실행 방법

Windows x64와 .NET 10 SDK가 필요합니다.

1. 프로젝트 전체를 다운로드하고 압축을 풉니다.
2. `src` 폴더와 같은 위치에 있는 `Run.cmd`를 실행합니다.

배포용 실행 파일을 만들려면 `Publish.cmd`를 실행하세요. 결과는 `artifacts\win-x64`에 생성됩니다. 해당 폴더 전체를 함께 보관하고 `findowgrid.exe`를 실행합니다.

## 사용 방법

### Workspace 저장

1. 사용할 프로그램을 직접 열고 원하는 위치에 배치합니다.
2. **Save Current Workspace**를 누릅니다.
3. 저장할 창을 선택하고 이름을 입력합니다.
4. **SAVE**를 누릅니다.

### Workspace 복원

카드의 **OPEN**, 지정한 전역 단축키 또는 트레이 메뉴를 사용합니다.

대상 Workspace를 복원한 뒤, 다른 Workspace에 등록된 것으로 확인된 창은 최소화합니다. 공유 창과 등록하지 않은 창은 그대로 유지합니다.

### Workspace 편집

카드의 **EDIT**에서 이름, 단축키, 창 목록, 실행 경로와 URL을 변경할 수 있습니다.

배치를 수정하려면 실제 창을 원하는 위치로 옮긴 뒤 **Update with Current Screen → SAVE**를 누르세요.

### 자동 시작과 종료

- **설정 → Windows 시작 설정**에서 자동 시작과 마지막 Workspace 복원을 켤 수 있습니다.
- 메인 창을 닫으면 트레이로 이동합니다.
- 완전히 종료하려면 트레이 메뉴의 **Exit**를 선택하세요.

## 관리 범위

findowgrid는 Windows의 독립된 최상위 창을 관리합니다.

- HTS 내부 차트·주문창·관심종목 레이아웃은 HTS에서 설정해야 합니다.
- 브라우저 탭 각각을 독립된 창처럼 배치하지는 않습니다.
- 로그인과 인증은 사용자가 직접 진행해야 합니다.
- 앱의 권한이나 창 크기 제한에 따라 일부 복원이 제한될 수 있습니다.

## 데이터 저장

Workspace와 설정은 로컬에 저장됩니다.

```text
%LOCALAPPDATA%\findowgrid\
```

금융 계좌, 비밀번호, 주문 내역, 브라우저 쿠키·세션 정보를 수집하지 않습니다. 자체 시세 제공, 주문 실행, 금융 데이터 수집 기능은 포함하지 않습니다.

## 개발 환경

C# · .NET 10 · WPF · Win32 API
